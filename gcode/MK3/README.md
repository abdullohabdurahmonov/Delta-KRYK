# MK3 (V3.3 set) G-code for Elegoo Neptune 4 Max (0.4 mm)

Plates A1..A5 print the full set (93 pieces, quantities taken from the `Nx_` file-name prefix); OPT holds the optional MKS PWC/DET parts.
Each zip contains one `.gcode`. See `PARTS_LIST.txt` for what is on each plate and `layout.png` for the bed layout.

- `PETG/`   nozzle 240 C, bed 80/75 C, fan 30%
- `PLA-FC/` nozzle 235 C, bed 60/55 C, fan 80% (label range 225-255 C / 50-60 C)

Not included: effector, diffusers, hotend mount (hotend not chosen yet), older V3/V3.1/V3.2 frames and arms.
G-code was generated by a custom slicer script and has not been test-printed yet: watch the first layer.
NEMA17 mount and parts next to the controller/drivers are better printed in PETG.
